# Como seu projeto será avaliado

*Sprint 6 · Automação de Decisões de Vendas e Escala com Base no Clima*

Use esta tabela como checklist antes de enviar seu projeto. Ela mostra o que diferencia cada faixa de desempenho.

| Faixa | Nota | O que significa para este projeto |
|---|---|---|
| **Excelente** | **9–10** | Fluxo totalmente automatizado (Agendamento → OpenWeather → Gemini → Gmail), testado com dados reais. Chave da API configurada e testada no Postman antes do Zapier, com compreensão clara da URL e parâmetros. Prompt claro que sempre retorna os 3 resultados exigidos, pronto para uso no e-mail. E-mail amigável e profissional, com previsão do tempo, resultados da IA e identidade visual, testado na caixa de entrada. Apresentação completa, com diagrama de fluxo, capturas de tela de todas as etapas e explicação de por que a automação é útil. Detalhes criativos bem pensados além do mínimo exigido. |
| **Bom** | **7–8** | Fluxo funciona no geral, mas com pequenos problemas (mapeamento incorreto ou formatação inconsistente). API funciona no Zapier, mas testes no Postman foram pulados ou parâmetros mal explicados. Prompt funciona na maioria das vezes, mas às vezes retorna formatação bagunçada. E-mail enviado mas com formatação básica ou confusa. Apresentação cobre a maior parte do conteúdo, mas falta diagrama ou algum detalhe. Alguns elementos criativos, mas limitados. |
| **Precisa Melhorar** | **5–6** | Fluxo funciona só parcialmente, com etapas que falham ou exigem correção manual. Chamada da API instável ou incompleta (unidades erradas, campo faltando). Prompt gera erros frequentes ou orientações confusas. E-mail enviado mas sem detalhes importantes. Apresentação mínima ou pouco clara, sem explicar como o fluxo ajuda o negócio. Esforço criativo mínimo além do básico. |
| **Insuficiente** | **0–4** | Nenhum fluxo de trabalho funcionando, ou etapas faltando. Nenhuma API de previsão do tempo usada, ou chave não funciona. Nenhuma etapa de IA incluída, ou prompt não gera resultado relevante. Nenhuma etapa de envio de e-mail, ou falha no envio. Nenhuma apresentação fornecida. Nenhuma personalização ou esforço extra. |

**Nota mínima de aprovação: 6,0**

*A etapa opcional de alerta de tempo severo não afeta sua nota se não for implementada. Ela só soma pontos extras de criatividade se for feita com qualidade.*
