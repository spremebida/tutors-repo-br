# Rubrica de Avaliação — Projeto

*Sprint 6 · Automação de Decisões de Vendas e Escala com Base no Clima*
*Uso interno — Tutor*

> O critério "Opcional — alerta de tempo severo" não é obrigatório para aprovação. Um aluno pode obter nota máxima nos demais critérios mesmo sem implementar essa etapa.

| Critério | Excelente | Bom | Precisa Melhorar | Ausente |
|---|---|---|---|---|
| **Configuração do fluxo de automação** | O fluxo de trabalho totalmente automatizado, desde o Agendamento → OpenWeather → Gemini → Gmail. Todas as etapas testadas com sucesso com dados reais (a previsão do tempo aparece corretamente no e-mail). | No geral, o fluxo de trabalho funciona, mas apresenta pequenos problemas (por exemplo, a temperatura não é mapeada corretamente ou a formatação dos e-mails é inconsistente). | Fluxo de trabalho funciona apenas parcialmente; uma ou mais etapas falham ou exigem correção manual a cada execução. | Nenhum fluxo de trabalho funcionando, ou etapas faltando. |
| **Integração da API OpenWeather** | A chave da API é configurada corretamente, testada no Postman e mapeada adequadamente no Zapier. O aluno demonstra compreensão clara da URL e dos parâmetros da requisição. | A API funciona no Zapier, mas os testes no Postman foram ignorados ou alguns parâmetros não estão bem explicados. | A chamada da API é instável ou incompleta (por exemplo, unidades incorretas, faltando campo de descrição). | Nenhuma API de previsão do tempo usada ou a chave não funciona. |
| **Design do prompt e saída de IA** | O prompt é claro, conciso e sempre retorna os 3 resultados exigidos: foco do produto, orientações sobre a equipe e 2 mensagens promocionais. O resultado é curto e pronto para uso no e-mail. | O prompt funciona na maioria das vezes, mas às vezes retorna uma formatação bagunçada ou inconsistente. | O prompt gera erros frequentes (muito prolixo, sem as promoções ou com orientações confusas). | Nenhuma etapa de IA incluída ou o prompt não gera resultados relevantes. |
| **Entrega de e-mails e formatação** | E-mail para o gerente amigável, profissional e mostra a previsão do tempo correta, os resultados da IA e a identidade visual da marca (assunto e corpo do e-mail). Testado com sucesso na caixa de entrada. | O e-mail é enviado, mas a formatação é básica ou um pouco confusa (por exemplo, todos os resultados da IA agrupados em um único bloco). | E-mail é enviado, mas faltam detalhes importantes (por exemplo, informações sobre o clima e promoções). | Nenhuma etapa de envio de e-mail, ou falha no envio. |
| **Clareza na demonstração e apresentação** | Apresentação educada e profissional. Inclui diagrama de fluxo, capturas de tela das etapas do Zapier, solicitação de API, prompt e um exemplo de e-mail. Explica por que essa automação é útil no clima instável do local escolhido. | A apresentação abrange a maior parte do conteúdo, mas falta alguns detalhes (por exemplo, não há diagrama, apenas capturas de tela parciais). | A apresentação é mínima ou não é clara. Falta uma explicação fundamental sobre como o fluxo de trabalho ajuda. | Nenhuma apresentação é fornecida. |
| **Opcional — alerta de tempo severo** | O alerta por e-mail está totalmente implementado e é acionado corretamente (acima de 33 °C, "tempestade" ou "chuva"). O aluno explica por que isso é importante para as operações do negócio. | O alerta foi configurado, mas não foi totalmente testado, ou as condições estão incompletas. | A etapa de alerta foi adicionada, mas é pouco confiável (falsos positivos ou nunca é acionada). | Nenhuma lógica de alerta incluída. Como é opcional, isso não penaliza a nota final. |
| **Criatividade e esforço extra** | O projeto inclui detalhes cuidadosamente pensados (por exemplo, frases personalizadas para as perguntas, emojis em e-mails, condições de filtro adicionais ou formatação de e-mail com a identidade visual da marca). | Alguns elementos criativos foram adicionados, mas são limitados ou não totalmente funcionais. | Esforço criativo mínimo além dos requisitos básicos. | Nenhuma personalização ou esforço extra demonstrado. |
